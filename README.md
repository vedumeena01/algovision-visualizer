# 🔮 AlgoVision — Interactive Algorithm Visualizer & DSA Studio

[![JavaScript](https://img.shields.io/badge/Language-JavaScript%20(ES6%2B)-F7DF1E.svg?logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![React](https://img.shields.io/badge/UI-Modern%20Web%20App-61DAFB.svg?logo=react)](https://reactjs.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An interactive, responsive web application engineered to visually render **sorting algorithms** (Merge Sort, Quick Sort, Bubble Sort, Insertion Sort) and **graph pathfinding algorithms** (Dijkstra's, BFS, DFS) step-by-step.

---

## ⚡ Key Highlights

- 📊 **Sorting Visualizer:** Compare $O(N^2)$ vs $O(N \log N)$ sorting complexities with real-time bar height transitions.
- ⏱️ **Granular Playback Controls:** Adjustable execution speed sliders (1ms to 200ms delay) and custom array size generators (10 to 100 elements).
- 🧩 **Graph & Pathfinding Mode:** Grid-based visualization of shortest-path discovery using Dijkstra's Algorithm and Breadth-First Search.
- 🎨 **Modern Aesthetics:** Dark mode glassmorphism UI built with modern CSS3 Grid, Flexbox, and smooth 60fps animations.
